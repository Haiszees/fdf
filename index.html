04 — Применение

Голос бренда

Тон общения

  • Лаконично — одно сообщение, одна мысль
  • Структурировано — разделители ━━━
  • Технично, но без жаргона
  • Эмодзи как навигация, не декор
  • Не использовать восклицательные знаки
  • Не писать стенами текста

Сообщение бота

  • Заголовок с эмодзи + жирный
  • Разделитель ━━━━━━━━━━━━━━━━━━━━
  • Данные выровнены по столбцам
  • Числа с разделителями тысяч
  • Подсказка или команда в конце

Иконография

  • 🔫 Пули — донат-валюта
  • 🪙 Гильзы — игровая валюта
  • 🚜 Ферма — пассивный доход
  • ⚔️ Дуэль — PvP игры
  • 🏰 Клан — сообщество

Позиционирование

  • Профессиональный инструмент
  • Надёжный — не даёт сбоев
  • Многофункциональный
  • Для любых чатов — не нишевый
